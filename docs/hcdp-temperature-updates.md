# HCDP monthly mean air temperature

The [official HCDP example notebook](https://github.com/HCDP/hcdp_api_notebook/blob/main/workshop.ipynb) documents `GET /raster` with `datatype=temperature`, `aggregation=mean`, `period=month`, `date=YYYY-MM`, and `extent=statewide`. Its temperature example uses °C. This integration does not substitute daily extrema or a climatological average for a dated monthly mean raster.

`scripts/sync_hcdp_temperature_history.py` checks the previous 24 completed months using the repository's `HCDP_API_TOKEN` GitHub Actions secret. It omits unpublished months, rejects implausible values or invalid geographic bounds, and never prints the token. A complete validated candidate becomes `assets/data/temperature-monthly/YYYY-MM/{temperature-values.png,temperature-overlay.png,temperature-metadata.json}`. The index `assets/data/temperature-months.json` lists only verified months. PNG values use RGB lossless encoding with 0 reserved for missing cells and `temperature_C = (integer - 1) / 10 - 100`; this preserves negative and zero temperatures independently of rainfall encoding.

The Temperature Map reads only the verified index and loads one selected month at a time. Until the first authenticated download and data PR have been reviewed and merged, it remains explicitly unavailable. Daily temperature and case-paper climate matching are not included; the existing NbS case results remain unchanged. The map supports a range mask, point query and CSV download with coordinates, month, °C, source, dimensions, bounds and missing-cell rule after verified data is published.

The branch-only workflow run verifies September 2026 in an isolated runner directory and uploads a one-day artifact without changing website files. Once the implementation is reviewed and merged, the weekly scheduled run checks 24 months and opens a **data review PR**, never merging or deploying it automatically. Review the metadata, supported dates and Vercel preview before merging each data PR. HCDP's raster response does not provide a documented preliminary/final flag, so metadata states `not specified by API` rather than guessing.
